# Aviator Lab

Static GitHub Pages version of the offline historical-results analyzer.

## Deploy with GitHub Pages

1. Create a GitHub repository named `aviator-lab` (public if using GitHub Free).
2. Extract this ZIP.
3. Upload `index.html`, `style.css`, `script.js`, and `.nojekyll` to the repository root.
4. Commit the files to the `main` branch.
5. Open **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select branch `main`, folder `/(root)`, then click **Save**.
8. Wait for the Pages deployment to finish. The published URL will be shown in Settings → Pages.

## Data source status

This version does not connect to Crorebet or any live game feed. No authorized public results API was identified during preparation. Do not add guessed/private endpoints or betting credentials. To enable live result import, obtain API/feed documentation and authorization from the game/operator first.

The displayed multiplier is a historical median reference, not a forecast of the next crash point.
